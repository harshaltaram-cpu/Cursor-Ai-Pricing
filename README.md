# Cursor-Ai-Pricing

🚀 Cursor AI Pricing Page Clone

A modern and responsive SaaS pricing page UI inspired by Cursor AI’s pricing structure.
This mini project focuses on clean UI design, pricing comparison, and basic JavaScript interactivity.

🔧 Tech Stack

HTML5

CSS3 (Flexbox & Grid)

✨ Features

Responsive pricing cards (Free, Pro)

Monthly / Yearly pricing toggle

Feature comparison section

Clean and modern SaaS UI

Mobile-friendly design
